# CalyrexMod 开发文档（手写代码参考）

本 mod 为《Slay the Spire 2》纯原生 Mod：**0Harmony + sts2.dll**，零第三方 Mod 库（不依赖 RitsuLib/BaseLib 的功能 API）。
代码全部手写于 `mod_src/`，资源打包用自研 `tools/make_pck.py`（因游戏裸 png 无 .import 无法被 Godot 标准导出加载）。

---

## 1. 项目结构

```
sts2CalyrexMod/
├── mod_src/                 # C# 源码（唯一手写区）
│   ├── ModEntry.cs          # 入口：Harmony → 注册 → 序列化注入
│   ├── ModInfo.cs           # ModId / 版本号
│   ├── Characters/          # 角色（CalyrexCharacter）
│   ├── Cards/               # 卡牌（含 MountHelper 骑马逻辑、KeywordTipHelper）
│   ├── Powers/              # 能力（丰饶/冰冻/骑马标记等）
│   ├── Relics/              # 遗物
│   ├── Potions/             # 药水
│   ├── Monsters/            # 宠物（雪暴马 Glastrier / 灵幽马 Spectrier）
│   ├── Events/              # 事件（时拉比速递/培育屋）
│   ├── CardPools/RelicPools/PotionPools/  # 各池（GenerateAll 枚举）
│   └── Patching/            # 全部 Harmony Patch（图标/视觉/控制台修复等）
├── assets/
│   ├── localization/{eng,zhs}/*.json   # 本地化（必须打包进 pck）
│   ├── scenes/*.tscn        # 视觉场景（内嵌 PackedByteArray 图片）
│   ├── icons/               # 全部图标（png + 对应 .tres）
│   └── README_素材清单.md   # 素材替换清单（含卡面 slug 表）
├── tools/make_pck.py        # 手写 Godot 4.5 pck 打包器
├── build/                   # 构建产物（dll + pck）
├── game/                    # 整个游戏解包（只读参考，含 src/Core 全部 C# 源码）
├── src/ → game/src          # junction：Godot 编辑器解析游戏脚本（不参与编译）
├── scenes/, images/, themes/ … → game/ 对应目录（编辑器资源依赖挂载）
└── decompiled/              # sts2.dll 反编译工程（只读参考）
```

**游戏源码参考位置**：
- 卡牌代码：`game/src/Core/Models/Cards/*.cs`
- 命令类：`decompiled/MegaCrit.Sts2.Core.Commands/`（PowerCmd/CreatureCmd/PlayerCmd/CardCmd…）
- 模型类：`decompiled/MegaCrit.Sts2.Core.Models/`（CardModel/EventModel/PotionModel…）

## 2. 构建与部署

```bash
# 一条命令：编译 → 复制 dll/json 到游戏 mods → 自动打包 pck 并部署（csproj target）
dotnet build -c Release

# 启动游戏（日志在 C:/Users/yy150/AppData/Roaming/SlayTheSpire2/logs/godot.log）
powershell -Command "Start-Process 'D:\SteamLibrary\steamapps\common\Slay the Spire 2\SlayTheSpire2.exe' -WorkingDirectory 'D:\SteamLibrary\steamapps\common\Slay the Spire 2'"
```

> csproj 内置 3 个 target：`CopyModToGame`（dll+json）、`ExportPck`（Godot 装好后用官方导出）、`PackPckLegacy`（未装 Godot 时回退 make_pck.py）。

> 部署前先 `taskkill //F //IM SlayTheSpire2.exe`；删 godot.log 便于定位本次日志。
> 控制台：`~` 打开，`card XXX` 加牌、`event XXX` 跳事件、`help` 看命令。

## 3. 手写卡牌模板

```csharp
using System.Collections.Generic;
using System.Threading.Tasks;
using MegaCrit.Sts2.Core.Commands;
using MegaCrit.Sts2.Core.Entities.Cards;
using MegaCrit.Sts2.Core.GameActions.Multiplayer;
using MegaCrit.Sts2.Core.Localization.DynamicVars;
using MegaCrit.Sts2.Core.Models;
using CalyrexMod.Powers;

namespace CalyrexMod.Cards;

public sealed class MyCard : CardModel
{
    // 动态变量：所有数值都定义在这里（升级/附魔才可叠加）
    protected override IEnumerable<DynamicVar> CanonicalVars
    {
        get
        {
            yield return new IntVar("Damage", 6m);
            yield return new BlockVar(5m, ValueProp.Move);   // 格挡注意 ValueProp.Move
        }
    }

    public MyCard()
        : base(2, CardType.Attack, CardRarity.Common, TargetType.AnyEnemy)
    {
    }

    // 所属卡池（必须）
    public override CardPoolModel Pool => ModelDb.CardPool<CalyrexMod.CardPools.CalyrexCardPool>();

    // 关键词（消耗/固有/保留/永久）：
    // public override IEnumerable<CardKeyword> CanonicalKeywords => new[] { CardKeyword.Exhaust };

    protected override async Task OnPlay(PlayerChoiceContext choiceContext, CardPlay cardPlay)
    {
        await CreatureCmd.Damage(choiceContext, cardPlay.Target!, base.DynamicVars.Damage, base.Owner.Creature, this);
    }

    protected override void OnUpgrade()
    {
        base.DynamicVars["Damage"].UpgradeValueBy(3m);   // 升级用 UpgradeValueBy（勿直接改 BaseValue）
    }
}
```

**CardType**：Attack/Skill/Power/Status/Curse/Quest
**TargetType**：None/Self/AnyEnemy/AllEnemies/RandomEnemy/AnyAlly/AllAllies
**CardRarity**：Basic/Common/Uncommon/Rare/**Ancient**（先古，达弗给予）/Event/Token/Status/Curse

### 常用命令（签名确认自反编译）

```csharp
// 伤害 / 格挡 / 回复
await CreatureCmd.Damage(choiceContext, target, 6m, ValueProp.Unpowered, dealer, cardSource);
await CreatureCmd.GainBlock(owner.Creature, amount, ValueProp.Unpowered, cardPlay);
await CreatureCmd.Heal(creature, 5m, playAnim: false);
await CreatureCmd.GainMaxHp(creature, 4m);       // 喂养马（同时回满当前血）

// 能力
await PowerCmd.Apply<Abundance>(choiceContext, creature, 2m, applier, cardSource);
await PowerCmd.Apply<Abundance>(choiceContext, IEnumerable<Creature>, 2m, applier, cardSource); // 全体
await PowerCmd.ModifyAmount(choiceContext, power, 2m, applier, cardSource);  // 加层数
await PowerCmd.Remove<T>(creature);               // 移除某能力
await PowerCmd.TickDownDuration(power);           // 掉 1 层（持续类）

// 玩家资源
await PlayerCmd.GainEnergy(1m, player);
await PlayerCmd.GainGold(100m, player);
await PlayerCmd.LoseGold(100m, player);
await PlayerCmd.GainMaxPotionCount(1, player);

// 遗物 / 药水
await RelicCmd.Obtain(relicModel, player);
await PotionCmd.TryToProcure(potionModel, player);
await RelicFactory.PullNextRelicFromFront(player, rarity, filter).ToMutable(); // 随机遗物

// 击晕
await CreatureCmd.Stun(creature, (_) => Task.CompletedTask);

// 抽牌 / 选牌
await CardPileCmd.Draw(choiceContext, 2m, player);
await CardSelectCmd.FromHand(choiceContext, player, prefs, filter, source);          // 手牌选
await CardSelectCmd.FromCombatPile(choiceContext, pile, player, prefs, filter);      // 牌堆选
await CardSelectCmd.FromDeckForUpgrade(player, prefs);                                // 选升级
await CardSelectCmd.FromDeckForEnchantment(player, enchantment, amount, prefs);       // 选附魔
// prefs: new CardSelectorPrefs(CardSelectorPrefs.EnchantSelectionPrompt, 1) 等

// 选牌提示文案：本地化 key `cards.{ID}.selectionScreenPrompt`
```

## 4. 手写能力（Power）模板

```csharp
using System.Threading.Tasks;
using MegaCrit.Sts2.Core.Commands;
using MegaCrit.Sts2.Core.Entities.Creatures;
using MegaCrit.Sts2.Core.Entities.Powers;
using MegaCrit.Sts2.Core.GameActions.Multiplayer;
using MegaCrit.Sts2.Core.Models;

namespace CalyrexMod.Powers;

public sealed class MyPower : PowerModel
{
    public override PowerType Type => PowerType.Buff;        // Buff / Debuff
    public override PowerStackType StackType => PowerStackType.Counter;  // Counter=可叠加(层数) Single=唯一

    // 效果 hook（部分常用）：
    // public override async Task AfterSideTurnStart(CombatSide side, IReadOnlyList<Creature> participants, ICombatState combatState)
    // public override async Task AfterSideTurnEnd(PlayerChoiceContext ctx, CombatSide side, IEnumerable<Creature> participants)
    // public override decimal ModifyDamageMultiplicative(Creature? target, decimal amount, ValueProp props, Creature? dealer, CardModel? cardSource)
    // public override async Task AfterCardPlayed(PlayerChoiceContext ctx, CardPlay cardPlay)
    // public override async Task AfterCurrentHpChanged(Creature creature, decimal delta)
    // public override async Task AfterDeath(PlayerChoiceContext ctx, Creature creature, bool wasRemovalPrevented, float deathAnimLength)
}
```

> **可叠加规则**：`StackType = Counter`，效果内用 `base.Amount`（层数）缩放，重放/重复打出即叠加。
> `AfterSideTurnEnd` 中 `side == CombatSide.Enemy` 表示敌人回合结束（冰冻掉层、再来一次重复行动都用它）。
> 战斗结束清理：玩家 Power 在 AfterCombatVictory 前被移除 → 回血用 `AfterCombatEnd` + `Heal(playAnim:false)`。

## 6. 手写事件模板

```csharp
public sealed class MyEvent : EventModel
{
    // 出现条件：通用/层数限制/角色限定
    public override bool IsAllowed(IRunState runState)
    {
        if (runState.CurrentActIndex != 1) return false;          // 仅第 2 层
        return runState.Players.All(p => p.Character is CalyrexCharacter);  // 蕾冠王专属
    }

    protected override IReadOnlyList<EventOption> GenerateInitialOptions()
    {
        return new EventOption[]
        {
            new EventOption(this, OptionA, "MY_EVENT.pages.INITIAL.options.OPTION_A"),
            new EventOption(this, OptionB, "MY_EVENT.pages.INITIAL.options.OPTION_B"),
        };
    }

    private async Task OptionA()
    {
        await PlayerCmd.GainGold(100m, base.Owner);
        SetEventFinished(L10NLookup("MY_EVENT.pages.DONE.description"));
    }
}
```

- 注册：`Patching/EventPoolPatches.cs` 的 `AllSharedEventsPostfix` 追加（共享池）；`IsAllowed` 控制层/角色。
- 事件肖像：`EventModel.get_InitialPortraitPath` 由 `EventPortraitPatches` 指向 `res://CalyrexMod/icons/events/{id}.tres`（必须，否则预加载挂起卡死）。
- 本地化 key：`{ID}.title`、`{ID}.pages.INITIAL.description`、`{ID}.pages.INITIAL.options.{KEY}.title/.description`、`{ID}.pages.{PAGE}.description`。

## 7. 本地化与 slug 规则（重点！）

- 语言码：`eng` / `zhs`（不是 zh）。
- 文件：`assets/localization/{lang}/{cards,powers,relics,potions,events,monsters,characters,...}.json`。
- **key = 类名转大写蛇形**，如 `MyCard → MY_CARD.title / MY_CARD.description`。
- **坑**：连续大写之间也会插下划线！`PPRestoreCard → P_P_RESTORE_CARD`（运行时日志验证）。
- 卡面 slug 不同：`PPRestoreCard → pp_restore_card`（连续大写合并，卡面是 `card_atlas.sprites/calyrex/{slug}.tres`）。
- 动态变量显示：描述里用 `{Damage}` / `{Block:diff()}`（升级高亮）。
- 富文本标签：`[gold]X[/gold]`、`[green]X[/green]`、`[blue]X[/blue]`、`[orange]X[/orange]`。

## 8. 图标 / 素材

- 规则：`xxx.png`（源图） + `xxx.tres`（RGBA PackedByteArray 内嵌，脚本生成，勿手改）。
- 图标尺寸：标记/遗物/药水 128×128；卡面 1000×760；事件背景 2560×1200；角色立绘 475×475；角色选择背景 2560×1200。
- 全部素材清单见 `assets/README_素材清单.md`。
- Power/遗物/药水图标通过 `Patching/*IconPatches.cs` 指向 `res://CalyrexMod/icons/...`；药水另有模拟 `images/atlases/potion_atlas.sprites/{slug}.tres` 路径（AtlasManager fallback 会读 `images/potions/{slug}.png`）。

## 9. Harmony Patch 规范

- 全部 try-catch（游戏内一处异常可能整场卡死）。
- 不能 patch Godot 生命周期方法（`_Ready` 等）；普通 C# 方法/属性 getter 可 patch。
- 已有关键 patch：
  - `CharacterPatches`：角色各路径（视觉/图标/能量/商店/火堆/角色选择背景）
  - `MountedVisualPatches`：骑马合体换皮
  - `PotionIconPatches` / `RelicIconPatches` / `PowerIconPatches`：图标
  - `CardLibraryFix`：卡牌图鉴筛选按钮
  - `EventPoolPatches`：事件注册；`EventPortraitPatches`：事件肖像
  - `ArchitectDialogueFix`：先古对话兜底（防卡死）
  - `DevConsoleFix` / `HealthBarForceShow` / `PetPositionPatches` / `CharacterSelectButtonFix`

## 10. 常见坑清单

| 坑 | 解法 |
|---|---|
| 类名撞内置卡 → DuplicateModelException | 改名（Feed→CalyrexFeed、Uproar→UproarRoar 等） |
| 裸 png 无法加载 | 一律 .tres 内嵌 PackedByteArray |
| 本地化 key 连续大写插下划线 | 用日志验证实际 key |
| GainBlock 被清 0 | 用 `ValueProp.Move`（BlockVar 构造时） |
| 丰饶回血时机 | AfterCombatEnd + Heal(playAnim:false) |
| 骑马马死亡残留 | 先 `PowerCmd.Remove<SteedGuard>` 再 Kill |
| 战死马复活 | 喂养用 `CreatureCmd.GainMaxHp`（无需 IsAlive 检查） |
| 事件肖像缺失 → 进事件卡死 | patch `get_InitialPortraitPath` 指向 .tres |
| 角色过渡音效缺失 → 打完 Boss 卡死 | `CharacterTransitionSfx => "event:/sfx/ui/wipe_ironclad"` |
| 先古事件无角色对话 → 卡死 | `ArchitectDialogueFix` 兜底 |
| 新增模型要序列化 | ModEntry Stage3 `SavedPropertiesTypeCache.InjectTypeIntoCache` |
| Godot 编辑器报场景缺 `res://src/Core/...` 依赖 | 用 `mklink /J src game\src` 挂载游戏源码（mod 代码在 mod_src/） |
