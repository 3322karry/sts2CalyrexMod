# v1.2.18.107.1 更新说明

### Fixes / 修复
- **招式记录**：不再随机到先古/无色/调试牌；升级后选项为升级版消耗牌
- **抛下狠话**：升级后正确移除"消耗"（CanonicalKeywords 阶段 IsUpgraded 恒 false 的 bug）
- **冰冻血条覆盖层**：移除（未能生效，且疑似干扰敌人显示）
- **无色奖励**：不再刷出归零/星碎/雪矛（体系卡仅由专属卡生成）
- **威吓**：升级后 -1 点力量且不再消耗

### Changes / 改动
- **冰柱坠击**：3 点基础伤害，每层冰冻 +3（升级 +4）
- **青草滑梯**：每层丰饶 +2 伤害（升级 +3）
- **青草场地**：喂养 3、获得 2 层丰饶
- **击掌奇袭**：稀有度改回罕见（Uncommon）
